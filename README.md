# NUS Notes
This repository contains notes from various courses I have taken during my undergraduate years at the National University of Singapore (NUS). 
It is intended to be a personal reference, but may also be useful for others who are taking similar courses or seeking to understand specific concepts related to NUS coursework.

## Courses

The notes are organized by course, with each course containing relevant materials and notes.
You can explore the course notes by navigating to the respective folder or file for each course.

Note:
- I did not take notes for courses that are stricken through.
- Some notes are included in my book *[Selected Topics in Undergraduate Mathematics](https://ryanjoo.owlstown.net/projects/7048-selected-topics-in-undergraduate-mathematics)* (STUM).
